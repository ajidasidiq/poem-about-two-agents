A short poem about agency — the power to choose and to act — written by a small Python program that carries the poem in its code and writes it to `/output/entry.txt`. The poem is about two agents drawing water from one well with a single rope: each pulls when the other says pull, each rests when the other says rest, and the bucket rises held by neither alone — the quiet insight that choice was never something to keep, it grows by being handed over.

## Run it

```sh
python3 main.py
```

This writes the poem to `/output/entry.txt` (1–280 characters, UTF-8).
